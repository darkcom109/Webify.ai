# 🌐 Webify.ai

Webify.ai is an experimental **AI-powered random website generator**.  
It uses Hugging Face's hosted models (like `meta-llama/Llama-3.1-8B-Instruct`) to generate **unique, playful websites** on demand — complete with HTML, CSS, and JavaScript — all from scratch.
This project is specifically for experimental purposes.

---

## ✨ Features

- 🎨 **Random Website Generation** – Each request generates a completely new design.
- 🧠 **Powered by LLMs** – Uses Meta Llama 3.1 (or other open models) to create HTML, inline CSS, and JS.
- 🔄 **One-click Refresh** – Generate a new random website at any time.
- 🖼️ **Supports Images & Emojis** – Keeps things fun and creative.
- 💻 **Built with Flask** – Lightweight, simple to run locally.
